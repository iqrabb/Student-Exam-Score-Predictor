# Student Exam Score Prediction

## Project Overview
This project predicts student exam scores using a Machine Learning Regression Model.

The application is built using:
- Python
- Scikit-Learn
- Random Forest Regression
- Streamlit

## Features
User can enter:
- Learning Mode
- Subject
- Study Hours
- Retention Score
- Focus Level

## Machine Learning Model
Algorithm:
Random Forest Regressor

## Deployment
The application is deployed using Streamlit Cloud.
